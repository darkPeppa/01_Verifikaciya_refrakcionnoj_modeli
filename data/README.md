# Папка `data` — данные этапа 2: взаимодействие излучения с веществом линз

Здесь собраны результаты моделирования прохождения фотонов через линзы МИР 15–35 кэВ из SU‑8
с включённой физикой взаимодействий (фотоэффект, комптоновское и рэлеевское рассеяние,
флуоресценция) одновременно с точным преломлением на каждой параболической поверхности.

Всё в этой папке получено командой `run_windows.bat stage2` / `./run.sh stage2`
(скрипт `analysis/stage2_collect.py`) и воспроизводится побайтно: генератор лучей и Geant4 используют
фиксированное зерно (`source.seed = 20261018`).

## Как получены данные

| параметр | значение |
|---|---|
| программа | XrayCRLGeant4 (этот проект), Geant4 **11.4.2** |
| физика | `G4EmLivermorePhysics` (модели Livermore, данные EPICS2017) + собственный процесс преломления `XrayRefractionProcess`; общий гамма‑процесс выключен, чтобы процессы `phot`, `compt`, `Rayl` различались по имени; флуоресценция включена, оже‑каскад выключен; порог рождения вторичных частиц 1 мкм (фактически нижний предел 990 эВ) |
| материал | SU‑8: ρ = 1,24 г/см³, масс.% C 72,4; O 17,9; H 6,9; Sb 1,326; F 1,242; S 0,3493 (сумма 100,1173 % нормирована). δ(E) = 4,32·10⁻⁷·(25/E[кэВ])² |
| контрольный материал | `SU8_noSb` — тот же состав **без сурьмы** (остальное перенормировано), та же плотность и δ. Гипотетический материал: нужен, чтобы выделить вклад Sb |
| геометрия | 4 конструкции табл. 2 диссертации + два варианта объектива 2 (N = 145, 180): точные параболические поверхности, d = 10 мкм, зазоры из длины L, чередование X/Y (см. `docs/PHYSICS.md`) |
| пучок | монохроматический параллельный пучок вдоль оси, **равномерно по всей квадратной апертуре** \|x\|, \|y\| ≤ a (a = √(R(p−d))), один фотон = одно событие |
| статистика | 1000 фотонов (проверка), 100 000 (массивы при 25 кэВ и детальные прогоны у края), 50 000 (сканирование по энергии) |
| регистрация | плоскость за выходной гранью линзы (+5 мкм). Фотон, покинувший мир (поперечный размер ~±1,3 мм у объективов, ±5 мм у конденсоров) не через выходную плоскость, считается «рассеянным из пучка» |

### Классификация судьбы первичного фотона (колонка `fate`)

| значение | смысл |
|---|---|
| `unscattered` | дошёл до выходной плоскости **без единого взаимодействия** — только эти фотоны формируют фокус/изображение |
| `scattered_transmitted` | дошёл до выходной плоскости после ≥ 1 комптоновского/рэлеевского рассеяния — фон |
| `absorbed` | первичный фотон погиб во взаимодействии (практически всегда фотоэффект) |
| `lost` | рассеялся и покинул расчётную область не через выходную плоскость (ушёл из пучка вбок/назад) |
| `outside_aperture` | без взаимодействий, но прошёл вне параболической апертуры (при равномерном освещении апертуры — 0) |

Статистическая ошибка доли — биномиальная: √(p(1−p)/N).

## `00_attenuation/` — коэффициенты ослабления μ(E)

`mu_SU8_15-35keV.csv`, `mu_SU8_noSb_15-35keV.csv` — линейные коэффициенты ослабления материала
линзы, вычисленные `G4EmCalculator` из тех же моделей Livermore, что используются при трассировке.
Сетка: 15–35 кэВ с шагом 0,05 кэВ + 30,400–30,600 кэВ с шагом 0,002 кэВ (окрестность K‑края Sb).

| колонка | единицы | смысл |
|---|---|---|
| `energy_keV` | кэВ | энергия фотона |
| `mu_phot_per_cm` | 1/см | фотоэффект |
| `mu_compt_per_cm` | 1/см | комптоновское (некогерентное) рассеяние |
| `mu_rayl_per_cm` | 1/см | рэлеевское (когерентное) рассеяние |
| `mu_total_per_cm` | 1/см | сумма трёх (пары при этих энергиях нет) |
| `mu_over_rho_total_cm2_g` | см²/г | массовый коэффициент полного ослабления |
| `mu_phot_<Эл>_per_cm` | 1/см | вклад каждого химического элемента в фотоэффект (C, O, H, Sb, F, S) |

Проверка: при 25 кэВ μ_полн = 0,6596 см⁻¹ — совпадает со значением «μ = 0,66» дипломов (там ошибочно
указано 1/м), μ/ρ = 0,532 см²/г против 0,543 см²/г в дипломе (−2 %): табличное «μ_погл» дипломов —
это полное ослабление, а не только поглощение.

## `01_sanity_1000ev/` — проверка адекватности на малом числе событий

По 1000 фотонов 25 кэВ через каждый из 6 массивов; первые 40 фотонов каждого прогона записаны
с полной траекторией. Критерий адекватности (по постановке руководителя): **лучи, не испытавшие
взаимодействий, сходятся в расчётном фокусе**, взаимодействия распределены по всей длине линзы —
см. рисунки `figures/fig01_sanity_rays_*.png`.

| файл | содержание |
|---|---|
| `sanity_table.csv` | сводка: доли судеб фотонов, μ_полн, положение фокуса (от выходного торца и глобальное z) |
| `sanity_<линза>_25keV_summary.json` | полная сводка прогона (конфигурация, материал, компоновка, фокусы, блок `interactions`) — структура описана ниже |
| `sanity_<линза>_25keV_rays.csv.gz` | все 1000 фотонов, полный формат файла лучей программы (описание колонок — в `README.md` проекта, раздел «Выходные файлы»; новые колонки — как в `*_photons.csv.gz` ниже) |
| `sanity_<линза>_25keV_trace.csv.gz` | траектории первых 40 фотонов: каждая точка преломления (`status = refracted`) и каждое взаимодействие (`status = phot / compt / Rayl`, `surface = −1`) |
| `sanity_<линза>_25keV_interactions.csv.gz` | все взаимодействия первичных фотонов (формат — как в `02_…/*_interactions.csv.gz`) |

## `02_lens_arrays_25keV/` — массивы линз при 25 кэВ (по 100 000 фотонов)

### Сводные таблицы

**`table_fate_25keV.csv`** — куда уходят фотоны.
`lens`, `n_photons`; для каждой судьбы `frac_<судьба>` (доля) и `err_<судьба>` (стат. ошибка);
`edep_fraction_of_beam` — доля энергии пучка, выделившаяся в полимере линзы (все частицы события);
`edep_per_photon_keV` — то же на один падающий фотон, кэВ.

**`table_processes_25keV.csv`** — статистика процессов.
`n_<proc>` — число взаимодействий процесса; `frac_photons_with_<proc>` — доля фотонов, испытавших его
хотя бы раз; `frac_first_<proc>` — доля фотонов, у которых это было первое взаимодействие;
`mean_interactions_per_photon`; `n_secondary_electrons`, `n_secondary_gammas` — рождённые первичными
фотонами вторичные электроны (фото‑ и комптоновские) и фотоны (флуоресценция);
`n_secondary_gammas_at_exit` — вторичные фотоны, дошедшие до выходной плоскости.

**`table_beer_lambert_check_25keV.csv`** — независимая проверка физики+геометрии.
`mu_total_per_cm` — μ_полн материала; `mc_unscattered`, `mc_err` — доля фотонов без взаимодействий по
Монте‑Карло; `beer_lambert_expected` — ⟨exp(−μ_полн·L_i)⟩, где L_i — путь **того же** луча в полимере,
полученный отдельным прогоном той же выборки лучей без физики взаимодействий (учитывает искривление
лучей преломлением); `pull_sigma` = (МК − ожидание)/ошибка; `thesis_formula_5_2_6` — пропускание по
формуле (5.2.6) бакалаврской работы (без шероховатости, T = Tₓ·T_y, прямые лучи); `thesis_rel_dev` — её
относительное отклонение от МК; `mc_first_phot`, `expected_first_phot` — доля фотонов с первым
взаимодействием «фотоэффект»: МК и ожидание ⟨μ_ф/μ·(1 − e^(−μL))⟩.

**`table_focal_plane_25keV.csv`** — фокальная плоскость (z_F — параксиальный фокус по оси x).
`z_focus_mm`, `focus_from_lens_end_mm`, `efl_mm`; `n_unscattered_at_focus` — фотоны без взаимодействий;
`rms_x_unscattered_um`, `max_r_unscattered_um` — их геометрическое пятно (СКО по x и максимальный радиус);
`n_scattered_at_focus_plane` — рассеянные фотоны, дошедшие до выхода; `n_scattered_within_1um` — из них
попавшие в круг r < 1 мкм вокруг фокуса (фон в пятне); `median_r_scattered_um` — медианный радиус фона;
`thesis_spot_5_2_5_um` — размер пятна по формуле (5.2.5) бакалаврской работы
Δ = 0,66·√(λ·F·β/δ) с β = μ_полн·λ/(4π) и F = EFL (дифракционно‑абсорбционная оценка — реальный масштаб пятна,
геометрическое пятно идеальной линзы на порядки меньше); `effective_aperture_um` — сторона «прозрачного»
квадрата с тем же числом прошедших фотонов: 2a·√(доля без взаимодействий).
Для объектива 2 (N = 215) фокус лежит **внутри** линзы, поэтому фокальная плоскость не строится.

## `05_waist_plane_components/` — плоскость перетяжки: вклад разных эффектов

Для каждого массива при 25; 30,40; 30,60; 35 кэВ (по 100 000 фотонов, равномерно по апертуре) находится плоскость
перетяжки — плоскость минимальной RMS-ширины фотонов без взаимодействий (с учётом астигматизма X/Y это точка между
фокусами по x и y). Каждый падающий фотон относится к одной категории в этой плоскости.

**`table_waist_and_spot.csv`** — положение и размер перетяжки: `z_waist_mm`, `waist_from_lens_end_mm`
(отрицательное — перетяжка внутри линзы), `z_paraxial_focus_x_mm`, `z_paraxial_focus_y_mm`,
`astigmatism_zx_minus_zy_mm`, `rms_radius_at_waist_unscattered_um` — геометрический RMS-радиус пятна фотонов без
взаимодействий (определяется астигматизмом скрещённой схемы), `spot_estimate_thesis_5_2_5_um` — размер пятна по
формуле (5.2.5) (дифракция + поглощение), `efl_mm`, `waist_position` (after_lens / inside_lens).

**`table_waist_plane_components.csv`** — разложение для радиусов пятна 0,1; 1; 10 мкм:
`n_incident` — падающие фотоны; `n_spot_unscattered` / `n_halo_unscattered` — без взаимодействий в пятне / вне его;
`n_spot_rayleigh`, `n_halo_rayleigh` — испытавшие только рэлеевское рассеяние; `n_spot_compton`, `n_halo_compton` —
испытавшие комптоновское рассеяние; `n_absorbed`; `n_lost` — рассеяны из пучка и не дошли до плоскости;
`n_fluorescence_at_plane`, `n_fluorescence_in_spot` — вторичные фотоны (флуоресценция); `pct_in_focal_spot`,
`pct_noise_at_plane`, `pct_absorbed`, `pct_scattered_out_of_beam` — те же величины в % от падающих.

**`<линза>_<E>keV_photons_ntuple.csv.gz`** (объектив 1 и конденсор 2) — «n‑tuple» по фотонам: одна строка на
падающий фотон со всеми величинами (судьба, число взаимодействий каждого типа, первое взаимодействие, место
поглощения, положение и направление на выходной плоскости, энергия на выходе, энерговыделение, число вторичных).
Колонки — как в `02_…/*_photons.csv.gz`, плюс `z_exit_mm`, `n_sec_gamma`, `n_sec_electron`. Это аналог ROOT n‑tuple:
любую плоскость z за линзой можно получить экстраполяцией прямой.

**`<линза>_<E>keV_secondaries_exit.csv`** — вторичные фотоны на выходной плоскости для тех же прогонов.
**`waist_<линза>_<E>keV_summary.json`** — полные сводки прогонов.

и векторными оригиналами без подписи (PDF, для статьи и постера). Полный список с подписями и указанием исходных
файлов данных — **`figures/FIGURES.md`**. Подписи осей, легенды и заголовки — на русском.

`run_log.csv` — время каждого прогона, с.

## Первичные выводы

Ниже — выводы по этим данным (ошибки — статистические, 1σ; 100 000 фотонов на точку, если не указано иное).

1. **Адекватность модели подтверждена.** При включённой физике фотоны без взаимодействий по‑прежнему сходятся в
   расчётном фокусе (рис. «пучок через массив», `01_…`), а доля таких фотонов совпадает с законом
   Бугера–Ламберта–Бера по преломлённым траекториям для всех 6 массивов: |pull| < 1
   (`table_beer_lambert_check_25keV.csv`). Geant4 даёт для SU‑8 при 25 кэВ μ = 0,6596 см⁻¹ (фотоэффект 56 %,
   Комптон 33 %, Рэлей 11 %) — то же 0,66 см⁻¹, что в дипломах.
2. **Куда уходят фотоны при 25 кэВ** (равномерное освещение всей апертуры):

   | массив | в фокус (без взаимодействий) | поглощены | рассеяны из пучка | рассеяны, но дошли до выхода | энергия, выделенная в линзе |
   |---|---|---|---|---|---|
   | объектив 1 (N = 154) | 34,7 % | 36,5 % | 28,7 % | 0,18 % | 35 % |
   | объектив 2 (N = 215) | 40,8 % | 33,3 % | 25,7 % | 0,13 % | 31 % |
   | объектив 2, N = 145 | 45,9 % | 30,4 % | 23,3 % | 0,30 % | 29 % |
   | объектив 2, N = 180 | 42,9 % | 32,1 % | 24,8 % | 0,20 % | 30 % |
   | конденсор 1 (N = 21) | 23,3 % | 43,8 % | 32,3 % | 0,62 % | 45 % |
   | конденсор 2 (N = 31) | 23,6 % | 43,5 % | 32,4 % | 0,49 % | 44 % |

   Основной канал потерь — фотоэффект; комптоновское и рэлеевское рассеяние почти целиком уводят фотон из пучка.
   Широкие конденсоры теряют больше: на краю их апертуры путь в полимере достигает ~5 см.
3. **Плоскость перетяжки** (`05_…`). В пятно r ≤ 1 мкм приходят **только** фотоны без взаимодействий; рассеянные
   (0,1–0,8 % падающих; из них ~70 % рэлеевские, ~30 % комптоновские) и флуоресценция Sb попадают в плоскость
   перетяжки на расстояниях от сотен мкм до мм от оси — ни один не попал в пятно. При ровном монохроматическом
   пучке фон в фокусе от взаимодействий в линзе пренебрежимо мал; эффект линзы — уменьшение сигнала, а не фон.
4. **Размер пятна и перетяжка.** Геометрическое пятно идеальной скрещённой линзы < 0,05 мкм и определяется
   астигматизмом: фокусы по x и y разнесены на 0,19–0,26 мм (объективы) и 1,6–2,3 мм (конденсоры).
   Реальный размер задают дифракция с поглощением — по формуле (5.2.5) 26–33 нм для объективов и 170–250 нм для
   конденсоров при 25 кэВ — и размер источника: расходимость 1 мкрад даёт σ = 82 нм у объектива 1 (`04_…`).
   Перетяжка объектива 2 (N = 215) при 25 кэВ лежит внутри линзы (−0,65 мм), при 30–35 кэВ — за ней.
5. **Сурьма** (`03_…`). 1,33 мас.% Sb дают уже при 25 кэВ 51 % фотопоглощения SU‑8. На K‑крае (между 30,48 и
   30,50 кэВ) полное ослабление растёт в 2,16 раза (0,471 → 1,019 см⁻¹), и доля фотонов без взаимодействий
   падает вдвое: объектив 1 — 42,4 → 20,5 %, конденсор 2 — 31,6 → 15,2 % (±0,2 %). Даже при 35 кэВ пропускание
   (25,7 % и 20,0 %) ниже, чем у самого края снизу. Для гипотетического SU‑8 без Sb скачка нет, а при 25 кэВ
   пропускание выше в 1,3 раза (45,8 % против 34,5 % у объектива 1). Над краем появляется флуоресценция Sb
   (Kα ≈ 26 кэВ, Kβ ≈ 29,7 кэВ) — до ~0,2 % от падающих фотонов на выходе, вне фокусного пятна.
   **Следствие:** рабочую энергию МИР с линзами SU‑8 выгодно держать чуть ниже 30,49 кэВ (максимум пропускания в
   диапазоне 30,0–30,48 кэВ), а резист с меньшей долей Sb увеличил бы пропускание линз.
6. **Формула (5.2.6)** бакалаврской работы (прямые лучи) занижает пропускание длинных объективов на 18–37 %
   (лучи сходятся внутри линзы и проходят меньше материала); для конденсоров она точна до 1 %.
7. Фокус смещается с энергией (δ ∝ E⁻²): объектив 1 — 38,1 мм от торца при 25 кэВ, 71,8 мм при 30,48 кэВ,
   104,3 мм при 35 кэВ; положение образца и детектора МИР придётся перестраивать при смене энергии.
