## Главные выводы верификации

1. Векторное преломление в Geant4 реализовано корректно до уровня машинной точности (10⁻¹⁵ рад на плоской
   границе, 10⁻¹¹…10⁻¹⁰ относительного расхождения с независимой матричной моделью для 300–430 элементов).
2. Значения FL таблицы 2 — тонколинзовые величины R/(2Nδ). Для длинных объективов реальное положение
   фокуса существенно иное: объектив 1 при 25 кэВ — 3,81 см от выходной грани (таблица 6,8 см; EFL 8,33 см),
   объектив 2 с N = 215 при 25 кэВ фокусирует **внутри** линзы. Формула (1.7.3) f + L/6 даёт для объектива 1
   8,11 см от центра против 7,86 см точного расчёта — погрешность 3 %; для конденсоров она точна до 10⁻⁵.
3. Полигональное представление поверхности сходится только как 1/n: при 1024 хордах ошибка отклонения
   0,14 %, поэтому для слабого преломления нужен точный решатель (`ParabolicLensSolid`), а не тесселяция.
4. Геометрические аберрации идеальных параболических элементов пренебрежимо малы (RMS в фокусе ~10⁻⁵ мкм
   для 90 % апертуры); реальный размер фокуса определят дифракция, поглощение (эффективная апертура) и
   погрешности изготовления — задачи следующих этапов.

## Допустимые численные погрешности

* направление после преломления: ~10⁻¹⁶ абсолютная (2 ULP), отклонение — 10⁻⁹ относительная;
* положения на границах: допуск Geant4 10⁻⁹ мм (1 пм), смещение от процесса преломления — 0;
* фокус по методу A: остаточный член O(h⁴) после экстраполяции Ричардсона; при h = 1 % апертуры
  расхождение с матрицей ≤ 2·10⁻¹⁰ EFL;
* метод B: точная замкнутая форма; табуляция — с шагом `rms_scan_points`.
