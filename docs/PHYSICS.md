# Физическая и математическая модель (этап 1 — верификация рефракционной модели)

## 1. Соглашения

* Система координат: **z** — оптическая ось и направление пучка, **x**, **y** — поперечные координаты.
  `z = 0` — входная грань первого элемента; линза занимает `[z_start, z_end] = [0, L_built]`.
* Внутренние единицы — единицы Geant4 (мм, МэВ). Во входных файлах: мкм, мм, кэВ (суффиксы в именах ключей).
* Комплексный показатель преломления: **n = 1 − δ + iβ** при временной зависимости поля **exp(−iωt)**
  (β > 0 — затухание). На этапе 1 используется только вещественная часть n = 1 − δ; поглощение и
  стохастические процессы выключены (`physics.em = "none"`).
* δ хранится и передаётся как δ, а не как 1 − δ: величина порядка 10⁻⁷ иначе теряет 7 значащих цифр.

## 2. Геометрия одного линейного двояковогнутого элемента

Локальная система элемента: x — фокусирующая координата u, y — нефокусирующая (направление
«вытягивания» структуры), z — ось, начало в центре перемычки.

Поверхности (как в бакалаврской работе, разд. 4.1, после сдвига начала в центр перемычки):

* входная: z = −s(x), выходная: z = +s(x), **s(x) = d/2 + x²/(2R)**;
* локальная толщина **t(x) = d + x²/R**, материал находится между поверхностями;
* грани z = ±p/2 обрезают параболы при |x| = **a = √(R(p − d))** — это параболическая (оптически активная)
  полуапертура; при |x| > a элемент — плоский блок толщиной p (опциональная рамка `frame_um`).

Тело элемента: `|x| ≤ a + frame, |y| ≤ H/2, |z| ≤ p/2, |z| ≤ s(x)`.

Связь с таблицей 2: p = d + A²/(4R). Для всех четырёх конструкций это даёт **d ≈ 10 мкм**
(объектив 1: 235 − 90²/36 = 10,000; объектив 2: 160 − 60²/24 = 10,000; конденсор 1: 9,986; конденсор 2: 9,662).
d = 10 мкм используется как реконструированное значение (в бакалаврской работе d = 10 мкм указано явно
для конденсора 2) и задаётся в файле линзы. При d = 10 мкм апертура, вычисленная как 2a, равна табличной A
с точностью 0,01 % (конденсор 2: 608,93 мкм против 609).

Высота H структуры (протяжённость в нефокусирующем направлении) в источниках не указана; по умолчанию
H = 4(a + frame), т.е. ортогональные элементы заведомо перекрывают всю апертуру.

## 3. Компоновка составной линзы

* **N — число элементов, фокусирующих в одном поперечном направлении** (таблица 2: «N, ед»). Полный
  комплект содержит **2N** одиночных элементов с чередованием X, Y, X, Y, … (бакалаврская работа,
  уравнения 4.2.2–4.2.5: границы i = 1…2N, k_x = 1 для нечётных элементов). Проверка: R/(2Nδ) с этим N
  воспроизводит 11 из 12 значений FL таблицы 2 с точностью ≤ 1,2 %.
  В диссертации формула (1.7.2) записана как F = R/(δN) для «N/2 линз», т.е. там N — число
  преломляющих элементов обоих направлений; в бакалаврской работе N = 31×2 для конденсора 2.
  Это одно и то же: R/(δ·2N) = R/(2Nδ).
* Режимы: `single` (один элемент), `pair` (X+Y), `full` (2N элементов), `slab` (плоская пластина для теста 2).
* Зазор g между элементами: `gap_mode = from_length` → g = (L − 2Np)/(2N − 1). Если g < 0
  (конденсор 1: 2Np = 97,902 мм > L = 97 мм), зазор принимается равным 0, длина восстанавливается как 2Np,
  в результатах выдаётся предупреждение. Элементы никогда не перекрываются. `gap_mode = fixed` — явный зазор.
* Центры элементов: z_i = p/2 + i(p + g), i = 0 … 2N−1.

## 4. Векторный закон Снеллиуса

Падающее направление k (|k| = 1), нормаль n ориентирована вдоль распространения (c = n·k > 0),
μ = n₁/n₂. Касательная составляющая сохраняется с множителем μ, нормальная определяется
сохранением |k′| = 1:

    k′ = μ k + (s − μ c) n,      s = √(1 − μ²(1 − c²)).

**Численно устойчивая форма.** Пусть ε = μ − 1 = (δ₂ − δ₁)/(1 − δ₂) (вычисляется без образования 1 − δ₁),
μ² − 1 = ε(2 + ε). Тогда

    s² = c² − ε(2 + ε)(1 − c²),
    s − μc = (s² − μ²c²)/(s + μc) = −ε(2 + ε)/(s + μc),
    k′ = (1 + ε) k − [ε(2 + ε)/(s + μc)] n.

В этой записи отклонение луча (~10⁻⁷…10⁻⁶ рад) вычисляется без катастрофического вычитания;
относительная погрешность отклонения ~10⁻⁹ (проверено против четверной точности, юнит‑тест).
**s² < 0** — преломлённого решения нет: полное внешнее отражение, k′ = k − 2c n
(из вакуума в SU‑8 при угле скольжения меньше √(2δ) ≈ 0,93 мрад при 25 кэВ).

## 5. Встраивание в Geant4: `XrayRefractionProcess`

Стандартные процессы Geant4 для `gamma` не преломляют рентгеновские фотоны; `opticalphoton` не
используется (это другая частица с другой физикой). Реализован собственный дискретный процесс:

1. `GetMeanFreePath` возвращает `DBL_MAX` с условием **Forced** — процесс никогда не ограничивает шаг,
   но его `PostStepDoIt` вызывается после каждого шага. Процесс регистрируется
   `G4ProcessManager::AddDiscreteProcess` с порядком PostStep по умолчанию, т.е. **после**
   `G4Transportation`, которая к этому моменту уже переместила трек в следующий объём
   (та же схема, что у `G4OpBoundaryProcess`).
2. Преломление применяется только если `postStepPoint->GetStepStatus() == fGeomBoundary`
   (шаг закончился на геометрической границе) и материалы по обе стороны различаются по δ.
3. **Шаг нулевой длины** (≤ поверхностного допуска 1 нм) не преломляется: это навигатор возвращает
   отражённый фотон через ту же поверхность. Так исключено двойное применение и зацикливание.
4. Нормаль берётся из решателя того тела, которому принадлежит граница (более глубокий из объёмов
   pre/post — дочерний объём, в который входят или из которого выходят), в его локальной системе,
   и поворачивается в глобальную через `G4AffineTransform::InverseTransformAxis`.
   Для точного тела это аналитический градиент (−x/R, 0, ±1)/√(1 + x²/R²).
5. Меняется только направление (`ProposeMomentumDirection`); положение, энергия и поляризация не
   трогаются — процесс не вносит поперечного смещения. Нормировка восстанавливается явно.
6. Включение/выключение: `refraction.enabled` в конфигурации или `/xrcl/refraction/enable`.

## 6. Точное тело `ParabolicLensSolid`

Geant4 не имеет готового тела «параболический цилиндр, обрезанный плоскостями». Аппроксимация
`G4TessellatedSolid`/`G4ExtrudedSolid` даёт ошибку наклона нормали ~Δx/(2R) у каждой хорды, что
сравнимо с самим преломлением; поэтому основное тело реализовано как **собственный `G4VSolid`** с
аналитическими пересечениями:

* Пересечение луча p + t v с параболой z = ±s(x) — квадратное уравнение
  ∓(v_x²/2R) t² + (v_z ∓ p_x v_x/R) t + (p_z ∓ s(p_x)) = 0, корни устойчивой формулой
  q = −(b + sign(b)√D)/2, t₁ = q/a, t₂ = c/q (вырожденный случай v_x = 0 — линейное уравнение).
* Все кандидаты (6 плоскостей + до 4 корней) сортируются, и каждый интервал между соседними
  кандидатами классифицируется по середине (`Inside`). Это корректно для невыпуклого тела:
  `DistanceToIn` — начало первого внутреннего интервала, `DistanceToOut` — конец связного внутреннего участка.
* `SurfaceNormal` — градиент ближайшего ограничения (на рёбрах — нормированная сумма).
* Безопасные расстояния — строгие нижние оценки: для `DistanceToOut(p)` используется касательная к
  выпуклой функции s(x) (расстояние до касательной ≤ расстояния до параболы), для `DistanceToIn(p)` —
  оценка с максимальным наклоном |s′| ≤ X/R.
* `GetPointOnSurface` (для проверки перекрытий) — выборка по площадям граней, на параболе — с весом длины дуги.
* Для визуализации тело переводится в многогранник через `G4ExtrudedSolid`.

Режим `geometry.surface = "tessellated"` строит тот же элемент как `G4ExtrudedSolid` с n хордами на
параболу — только для исследования влияния полигонального представления (тест 9).

## 7. Источник

Моноэнергетический параллельный пучок вдоль +z, один фотон = одно событие = один луч.
Режимы: `axis`, `offaxis` (смещение `offset_um`), `paraxial` (пары ±h, ±2h по x и по y,
h = `paraxial_fraction`·a), `grid` (n×n по квадрату ±f·a), `random` (равномерно, фиксированное зерно),
`fan_x`/`fan_y` (веер в одной плоскости). Наклон пучка — `tilt_urad`.

## 8. Определение фокуса

После выходной регистрационной плоскости лучи идут в вакууме по прямым, поэтому все величины за линзой
вычисляются точной экстраполяцией прямой (проверено тестом 12 сравнением с транспортом Geant4 до экранов);
мир длиной в сотни метров для одиночных элементов (f ≈ 10–100 м) не нужен.

**Метод A (пары параксиальных лучей).** Для пары лучей ±h пересечение x₊(z) = x₋(z):
z* = z_exit − (x₊ − x₋)/(t₊ − t₋), t = k_x/k_z; EFL(h) = −2h/(t₊ − t₋).
Аберрационный член ~h² исключается экстраполяцией Ричардсона по высотам h и 2h:
q₀ = (4q(h) − q(2h))/3. Работает и для наклонного пучка.

**Метод B (минимум RMS).** Для прямых x_i(z) = x_i + (z − z_exit) t_i дисперсия ширины —
квадратичная функция z, минимум в замкнутом виде: z_min = z_exit − cov(x, t)/var(t),
RMS_min² = var(x) − cov²(x,t)/var(t). Для графиков RMS(z) табулируется (`*_rms.csv`); тест 15
сверяет замкнутую форму с численным минимумом табуляции. Для полной апертуры минимум RMS отличается от
параксиального фокуса из‑за сферической аберрации длинной линзы.

**Метод C (матричная параксиальная оптика)** — независимая модель по реальным положениям элементов:
вектор (u, θ), на каждой поверхности n₂θ₂ = n₁θ₁ − (n₂ − n₁)κu (κ = −1/R для входной,
+1/R для выходной поверхности фокусирующего элемента, κ = 0 для нефокусирующего направления),
между вершинами — дрейф (внутри полимера — толщина d). Для системы [[A, B], [C, D]] от первой
до последней вершины: EFL = −1/C, BFL (от последней вершины) = −A/C, z_F = z_last + BFL,
задняя главная плоскость z_H′ = z_F − EFL.

**Выводимые величины** (`*_summary.json`, раздельно по x и y): глобальная координата фокуса; расстояние
от выходной грани линзы (z_end); от последней вершины; от центра линзы (для сравнения с формулой 1.7.3);
EFL; положение главной плоскости; разность z_x − z_y (астигматизм из‑за чередования элементов);
отклонения между методами и от аналитики.

## 9. Аналитические эталоны

* Тонкая линза: **f₀ = R/(2Nδ)** (N — элементов на направление).
* Непрерывная толстая линза: при равномерно распределённой оптической силе u″ = −u/(f₀L), ω = 1/√(f₀L):
  BFL от выхода = f₀·x/tan x, EFL = f₀·x/sin x, x = ωL = √(L/f₀). Разложение при малых x:
  фокус от центра = f₀ − L/3 + L/2 = **f₀ + L/6** — это формула (1.7.3) диссертации, т.е. она верна только при L ≪ f₀.
  Для объектива 2 (N = 215, 25 кэВ) x = 1,58 > π/2: фокус лежит **внутри** линзы (BFL < 0) — физически допустимо.

## 10. Модели δ(E)

| `delta.model` | формула | источник/ограничения |
|---|---|---|
| `power_law` (по умолчанию) | δ = δ_ref (E/E_ref)^(−2) | δ(25 кэВ) = 4,32·10⁻⁷ (дипломы); тождественно формуле (1.7.4) δ = 1,7564·10⁻⁶ λ²[Å] до 4 знаков; не годится у K‑края Sb (30,49 кэВ) |
| `constant` | δ = const | тесты (δ = 0, 10⁻³ …) |
| `table` | лог‑лог интерполяция CSV `energy_keV,delta` | без экстраполяции; приложенный файл — значения формулы (1.7.4), не измерения |
| `free_electron` | δ = r_e λ² n_e/(2π), n_e из `G4Material` | пренебрегает аномальной дисперсией f′(E); для SU‑8 при 25 кэВ даёт 4,38·10⁻⁷ (+1,4 % к 4,32·10⁻⁷) |

Табличные значения δ(E), отсутствующие в источниках, не придумываются. У K‑края Sb нужны данные
с учётом f′(E) (например, из таблиц Henke/Chantler) — задача этапа 3.

## 11. Этап 2: взаимодействие с веществом в той же геометрии

* `physics.em = "livermore"` добавляет `G4EmLivermorePhysics` (фотоэффект, комптоновское и рэлеевское
  рассеяние по данным EPICS2017, флуоресценция); процесс преломления работает поверх него без изменений:
  преломление по‑прежнему применяется только на геометрических границах, после комптоновского рассеяния
  δ берётся при новой энергии фотона. Общий гамма‑процесс (`GammaGeneralProc`) выключен, чтобы каждое
  взаимодействие было видно под своим именем.
* Для каждого первичного фотона записываются все взаимодействия (процесс, элемент, точка, энергия до/после,
  угол, вторичные частицы), его судьба, энерговыделение в полимере, вторичные фотоны на выходе.
* Независимая проверка: доля фотонов без взаимодействий должна равняться ⟨exp(−μ_полн·L)⟩, где L — путь
  луча в полимере по преломлённой траектории (из прогона без физики с теми же лучами), μ — из
  `G4EmCalculator`. Результат: совпадение в пределах статистики (|pull| < 1) для всех 6 массивов.
* Формула (5.2.6) бакалаврской работы считает лучи прямыми; в длинных объективах лучи сходятся внутри линзы
  и проходят меньше материала, поэтому формула занижает пропускание объективов на 18–37 %
  (для конденсоров верна до 1 %).
* Порог рождения вторичных частиц 1 мкм (по энергии — нижний предел 990 эВ): все фото‑ и комптоновские
  электроны и флуоресценция Sb (K ≈ 26–30 кэВ, L ≈ 3–4 кэВ) рождаются явно.
